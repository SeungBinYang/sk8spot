# 핵심 사용자 흐름

> 형식: `화면 → 행동 → 다음 화면`. 화면 내부 구성은 [SCREEN_STRUCTURE](SCREEN_STRUCTURE.md)를 본다.
> 흐름에 등장하는 상태·규칙의 근거는 [TRUST_AND_MODERATION](TRUST_AND_MODERATION.md).

**설계 원칙: 로그인 벽은 지도 앞이 아니라 쓰기 행동 앞에 둔다.**

---

## F1. 처음 앱을 설치한 사람

```
[설치 → 앱 실행]
   ↓  (스플래시 없음, 권한 팝업 없음)
[지도 홈]  ← 기본 위치로 즉시 지도 렌더 + 스팟 마커 로드
   ↓  마커 확인 / "내 위치" 버튼 탭
[OS 위치 권한 팝업]  ← 여기서 처음 요청
   ├─ 허용 → [지도 홈] 내 위치로 이동 + 주변 스팟
   └─ 거부 → [지도 홈] 그대로. 하단에 "지도를 움직여 스팟을 찾아보세요" 안내
```

### 결정 사항

- **앱 실행 시 위치 권한을 요청하지 않는다.** 첫 화면의 권한 팝업은 이탈 요인이고,
  권한 없이도 지도는 보여줄 수 있다
- 초기 지도 중심 우선순위: `마지막 지도 중심(로컬 저장)` → `스팟 밀집 기본 좌표`
- **회원가입 유도 없음.** 온보딩 슬라이드 없음
- 권한 거부는 정상 경로다. 거부해도 앱의 80%가 동작한다

### 실패/예외

| 상황 | 처리 |
|---|---|
| 네트워크 없음 | 지도 SDK 기본 타일 + "스팟을 불러올 수 없습니다 / 다시 시도" |
| 화면 내 스팟 0개 (수도권 밖) | "이 지역엔 아직 스팟이 없어요. 첫 스팟을 등록해보세요" + 등록 CTA |
| 위치가 서비스 범위 밖 (해외 등) | 지도는 그대로. 범위 안내 배너 1회 |

## F2. 주변 스팟을 찾는 사람

```
[지도 홈]
   ├─ 지도 이동/확대 → (debounce 후) 해당 영역 스팟 재조회 → 마커 갱신
   ├─ 클러스터 탭 → 지도 확대 → 개별 마커 분리
   ├─ 상단 검색바 탭 → [지명 검색] → 지역 선택 → [지도 홈] 해당 좌표로 이동
   ├─ 필터 칩 탭 (전체 / 파크 / 스트리트) → 마커 필터링 (재조회 없이 클라이언트 처리)
   └─ 마커 탭 → [스팟 미리보기 시트]  ← 지도를 덮지 않는 하단 시트
                   ├─ 시트 드래그업 or 탭 → [스팟 상세]
                   └─ 시트 닫기 → [지도 홈]
```

### 결정 사항

- 마커 탭 → 바로 상세 화면으로 넘기지 않는다. **미리보기 시트**를 거친다.
  탐색 중인 사용자는 여러 스팟을 빠르게 훑는다. 화면 전환은 그 흐름을 끊는다
- 미리보기 시트에는 판단에 필요한 최소 정보만: 사진 1장, 이름, 타입, 거리, 상태 배지
- 필터는 조회 조건이 아니라 **표시 필터**다. 서버 재요청 없음 (MVP 기준 영역당 200개 이하)
- 지도 이동 시 "이 지역 재검색" 버튼을 쓰지 않고 자동 조회한다.
  다만 이동량/줌 변화가 임계값 미만이면 요청을 건너뛴다 → [ARCHITECTURE](ARCHITECTURE.md#지도-데이터-조회)

## F3. 특정 스팟 정보를 확인하는 사람

```
[스팟 상세]
   ├─ 사진 스와이프
   ├─ "길찾기" → OS 앱 선택 → [네이버맵/카카오맵 앱]
   ├─ "공유" → OS 공유시트 → 카톡 등 (딥링크 포함)
   ├─ "저장" → (비로그인) [로그인 시트] → 성공 시 저장 완료 상태로 복귀
   ├─ "정보 제보" → F5로 진입
   └─ "사진 추가" → (비로그인) [로그인 시트] → [사진 선택] → 업로드 → 상세 갱신
```

### 상세 화면이 답해야 하는 순서

정보를 나열하지 않고 **판단 순서대로** 배치한다.

1. **지금 갈 수 있나** — 상태 배지 + 마지막 확인일 (최상단, 사진보다 위)
2. **어떻게 생겼나** — 사진
3. **내가 탈 수 있나** — 장애물 종류, 난이도, 바닥
4. **쫓겨나나** — 킥아웃 위험도, 이용 좋은 시간대
5. **언제 갈까** — 조명/야간, 실내외, 무료/유료
6. **어떻게 가나** — 길찾기

### 상태별 표시

| 상태 | 상세 화면 |
|---|---|
| `active` + 최근 확인 | 배지 없음 (정상이 기본) |
| `active` + 180일 이상 미확인 | 회색 "정보 확인 필요 · 마지막 확인 N개월 전" |
| 열린 제보 있음 | 노란 "최근 제보가 있어요 (N건)" |
| `caution` | 노란 "제지 위험 / 이용 어려움 제보 다수" |
| `temporarily_closed` | 주황 "공사 등으로 일시 이용 불가" |
| `no_skating` | 빨강 "스케이트 금지 구역으로 제보됨" + **이용 비권장 문구** |
| `removed` | 회색 처리 + "철거됨" + 지도 마커 기본 숨김 |

> 금지/사유지 스팟도 등록은 허용하되, 상세에서 명확히 경고하고 앱이 이용을 권장하지 않음을 표시한다.

## F4. 새로운 스팟을 등록하는 사람

**가장 이탈이 쉬운 흐름.** 폼이 길면 P4(로컬 스케이터)가 떠난다.

```
[지도 홈] → FAB "+" 탭
   ↓
(비로그인) [로그인 시트] ─ 취소 → [지도 홈]
   ↓ 로그인 성공
[위치 지정]  ← 지도 중앙 고정 핀, 주변 기존 스팟이 회색 마커로 함께 표시
   ↓  핀 이동 중 실시간으로 반경 내 기존 스팟 감지
   ├─ 반경 내 기존 스팟 있음
   │     ↓
   │  [중복 확인 시트] "혹시 이 스팟인가요?" + 후보 리스트(사진·이름·거리)
   │     ├─ "네, 이 스팟이에요" → [스팟 상세] 사진 추가 모드  ← 등록 흐름 종료, 기여로 전환
   │     └─ "아니요, 다른 곳이에요" → 계속
   ↓ "여기로 지정"
[스팟 정보 입력]  ← 필수 필드만. 선택 필드는 접어둔다
   ↓ "등록"
[등록 완료] → [스팟 상세] (방금 등록한 스팟)
```

### 입력 필드 구성

**필수 (5개 이하로 유지)**
- 사진 1장 이상 (카메라/앨범)
- 스팟 이름
- 스팟 타입 (파크 / 스트리트 / 광장·공원 / DIY)
- 장애물 종류 (다중 선택)
- 난이도 (초급/중급/상급)

**선택 (접힘)** — 바닥 재질, 바닥 상태, 실내외, 무료/유료, 조명, 야간 가능,
킥아웃 위험도, 이용 좋은 시간대, 설명

> 선택 필드를 접어두는 것이 핵심이다. 처음 보이는 폼의 길이가 등록률을 결정한다.

### 결정 사항

- **위치 지정을 첫 단계로 둔다.** 정보를 다 입력한 뒤 중복이라고 알리면 최악이다
- 중복 후보 판정 반경은 스팟 타입에 따라 다르다 (스트리트 50m / 파크·광장 150m)
- 사진 필수는 타협하지 않는다. 등록 마찰은 늘지만 허위 등록을 가장 싸게 막는다
- 등록 직후 지도에 즉시 노출할지, 검수 후 노출할지 → [결정 필요](OPEN_DECISIONS.md)

## F5. 오래된 스팟 정보를 수정하려는 사람

**"수정 요청" 폼을 만들지 않는다.** 제보 버튼 4개로 대체한다.
자유 입력 수정 요청은 운영자가 하나씩 읽어야 하고, 사용자도 귀찮아한다.

```
[스팟 상세] → "정보 제보" 탭
   ↓
(비로그인) [로그인 시트]
   ↓
[제보 시트]  ← 버튼 4개
   ├─ ✅ "아직 있어요"        → 즉시 반영: last_verified_at 갱신, 열린 제보 감쇠 → 토스트
   ├─ 🚧 "지금은 못 타요"      → 사유 선택(공사/폐쇄/막힘) → 제보 접수
   ├─ 🚫 "없어졌어요 / 철거"   → 사진 첨부 권장 → 제보 접수
   └─ ✏️ "정보가 틀려요"      → 어떤 정보인지 선택 + 한 줄 메모 → 제보 접수
   ↓
[스팟 상세]  ← 토스트 "제보 감사합니다. 확인 후 반영됩니다"
```

### 반영 규칙 (요약)

- **제보 1건으로는 상태가 바뀌지 않는다.** 상세에 "최근 제보 있음" 배지만 붙는다
- 서로 다른 유저 3명이 30일 내 같은 유형 제보 → 자동 상태 전환
- `removed` / `no_skating` 전환은 **운영자 승인 필수**
- "아직 있어요"는 예외적으로 즉시 반영 (되돌리기 쉽고 부작용이 없다)

전체 규칙: [TRUST_AND_MODERATION](TRUST_AND_MODERATION.md#스팟-상태-전이-규칙)

### 별도 경로: 신고

제보와 신고는 다르다. 제보는 "정보가 바뀌었다", 신고는 "이건 있으면 안 된다".

```
[스팟 상세] → 우상단 ⋯ → "신고"
   → 사유 선택 (허위 스팟 / 부적절한 사진 / 스팸·광고 / 권리 침해 / 기타)
   → 접수 → 운영자 큐 (자동 상태 전환 없음)
```

## 로그인 시트 (공통 컴포넌트)

전체 화면 로그인 페이지를 만들지 않는다. **하단 시트**로 띄우고, 완료 후 원래 행동을 이어간다.

```
[하단 시트]
  "스팟을 등록하려면 로그인이 필요해요"
  [ 카카오로 계속하기 ]
  [ Apple로 계속하기 ]   ← iOS
  [ 나중에 하기 ]
```

- 로그인 성공 시 **중단된 행동을 자동으로 재개**한다 (등록 폼으로 복귀, 저장 완료 처리 등)
- 로그인 시점에 닉네임을 묻지 않는다. 자동 생성하고 나중에 바꾸게 한다
