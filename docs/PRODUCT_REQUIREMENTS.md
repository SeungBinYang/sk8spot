# 제품 정의

> 이 문서는 **"왜 만드는가"**만 다룬다. 기능 목록은 [MVP_SCOPE](MVP_SCOPE.md), 화면은 [SCREEN_STRUCTURE](SCREEN_STRUCTURE.md)를 본다.

## 1. 한 줄 정의

**스케이터가 직접 등록하고 함께 갱신하는, 스케이트 스팟 전용 지도.**

## 2. 해결하려는 문제

스케이터가 탈 곳을 찾는 방법은 지금도 이렇다.

- 인스타/유튜브 영상을 보고 **배경만으로 위치를 추측**한다
- 카톡방·DM으로 "거기 어디였지?" 하고 묻는다
- 직접 가봤더니 **공사 중이거나, 철거됐거나, 경비원이 쫓아낸다**
- 다른 동네·다른 도시에 가면 **아는 사람이 없으면 탈 곳을 모른다**

즉 정보가 **개인의 머릿속과 휘발성 채팅방에만** 있고, 축적되지 않으며, 시간이 지나면 썩는다.

### 핵심 통찰

일반 지도 앱은 **"이 장소가 무엇인가"**를 답한다.
스케이터가 필요한 답은 다르다.

> **여기서 탈 수 있는가 / 지금도 탈 수 있는가 / 쫓겨나는가**

이 세 질문에 답하는 것이 이 앱의 전부다. 여기에 기여하지 않는 기능은 넣지 않는다.

## 3. 핵심 사용자

한국(초기: 서울/수도권)에서 스케이트보드를 타는 사람. 정확히는 **탈 장소를 스스로 찾아야 하는 사람.**

부차 사용자: 롱보드·인라인·BMX·킥보드 이용자가 같은 장소 정보를 원할 수 있으나,
**MVP에서는 스케이트보드에만 최적화한다.** 대상을 넓히면 데이터 구조가 즉시 밋밋해진다.

## 4. 사용자 니즈

| 니즈 | 이 앱에서의 형태 |
|---|---|
| 지금 내 주변에 탈 곳이 있는지 즉시 알고 싶다 | 앱 실행 → 지도에 마커 |
| 가기 전에 헛걸음할지 판단하고 싶다 | 사진 + 현재 상태 + 마지막 확인 시점 |
| 내 실력에 맞는 곳인지 알고 싶다 | 난이도, 장애물 종류, 바닥 상태 |
| 쫓겨날 확률을 알고 싶다 | **킥아웃 위험도**, 이용 좋은 시간대 |
| 밤에도 탈 수 있는지 알고 싶다 | 조명 유무, 야간 이용 가능 여부 |
| 내가 아는 스팟을 남기고 싶다 | 등록, 사진 추가 |
| 정보가 틀렸을 때 고치고 싶다 | 상태 제보 |

## 5. 서비스 가치

- **개인 지식의 공공재화** — 로컬 스케이터 머릿속에만 있던 정보를 축적한다
- **헛걸음 제거** — 상태 정보가 갱신되므로 없어진 스팟에 가지 않는다
- **이동성** — 낯선 지역에서도 로컬처럼 탈 수 있다
- **스팟 아카이브** — 철거된 스팟도 기록으로 남는다 (한국 스트리트 스팟은 빠르게 사라진다)

## 6. 기존 서비스와의 차이

### vs 네이버지도 / 카카오맵 / 구글맵

| | 일반 지도 앱 | Skate Spot |
|---|---|---|
| 검색 대상 | 상호(POI) — 가게, 건물, 시설 | **지형지물** — 계단, 레일, 렛지, 뱅크 |
| 등록 주체 | 사업자, 지도 사업자 | 스케이터 |
| 위치 단위 | 건물/주소 | **건물 앞 계단 5단** 같은 세부 지점 |
| 상태 정보 | 영업중 / 폐업 | 이용 가능 / 제지 위험 / 공사중 / 철거 |
| "탈 수 있는가" | 답 없음 | 서비스의 전부 |

일반 지도에서 "강남 스케이트 스팟"을 검색하면 스케이트샵과 스케이트파크만 나온다.
**비공식 스트리트 스팟은 애초에 지도 데이터에 존재하지 않는다.**

### vs 스케이트파크 검색 / 지자체 체육시설 목록

| | 스케이트파크 목록 | Skate Spot |
|---|---|---|
| 대상 | 공식 시설만 (전국 수십~수백 개) | **비공식 스트리트 스팟 포함** (사실상 무제한) |
| 데이터 갱신 | 기관 갱신, 수년 단위 | 사용자 제보, 상시 |
| 정보 깊이 | 주소, 개장시간 | 바닥 재질, 장애물, 제지 위험, 시간대 |
| 실제 사용 빈도 | 파크 갈 때만 | 매 세션 |

스케이트파크만으로는 부족하다. 스트리트 스케이터의 세션 대부분은 파크 밖에서 일어난다.

### vs 기존 글로벌 스팟 앱

해외 서비스는 존재하지만 한국 데이터가 사실상 비어 있고, 한국 지도 품질과
한국식 로그인(카카오)이 맞지 않는다. **국내 밀도**가 이 서비스의 유일한 해자다.
→ 그래서 [콜드스타트 전략](DEVELOPMENT_ROADMAP.md#콜드-스타트-전략)이 개발만큼 중요하다.

## 7. 페르소나

### P1. 이제 막 시작한 초보 — "민수"

- **목적**: 사람 없고 바닥 평평한, 넘어져도 창피하지 않은 연습 장소를 찾고 싶다
- **문제**: 스팟 이름을 들어도 어딘지 모른다. 레일·계단은 아직 못 탄다. 잘 타는 사람들 사이에 끼기 부담스럽다
- **앱에서 원하는 것**: 집 근처 **플랫 위주 / 난이도 낮음 / 사람 적은 시간대** 장소
- **설계 시사점**: 난이도 필드가 없으면 이 사람은 앱을 못 쓴다. 초보에게 "계단 10단"은 정보가 아니라 위협이다

### P2. 스팟을 찾아다니는 중급 스트리트 스케이터 — "지훈"

- **목적**: 특정 트릭을 걸 수 있는 **특정 형태의 장애물**을 찾는다 (예: 낮은 렛지, 3단 계단)
- **문제**: 영상에서 본 스팟 위치를 모른다. 갔더니 바닥이 거칠거나 경비원이 있다
- **앱에서 원하는 것**: 장애물 종류로 탐색, 사진으로 확인, **킥아웃 위험도**, 탈 만한 시간대
- **설계 시사점**: 이 앱의 헤비 유저이자 주 공급자. **장애물 종류 필터와 사진 품질**이 이 사람을 잡는다

### P3. 낯선 지역에 간 스케이터 — "현우"

- **목적**: 출장·여행·이사로 온 지역에서 오늘 저녁 탈 곳
- **문제**: 아는 로컬이 없다. 검색해도 안 나온다
- **앱에서 원하는 것**: 지도 열자마자 주변 스팟, 거리순, 지금 갈 수 있는 곳
- **설계 시사점**: **비회원 즉시 열람**이 이 사람에게 가장 중요하다. 여기서 가입 벽을 만나면 이탈한다

### P4. 로컬 스케이터 / 시딩 파트너 — "태준"

- **목적**: 자기 동네 스팟 정보를 남기고, 로컬 씬에 기여하고 싶다
- **문제**: 좋은 스팟을 알지만 공유할 곳이 인스타 스토리뿐이라 며칠 뒤 사라진다. 한편 너무 알려져서 스팟이 막히는 것도 걱정한다
- **앱에서 원하는 것**: 빠른 등록, 내가 올린 스팟이 쓰인다는 감각, **과잉 노출에 대한 통제감**
- **설계 시사점**: 초기 공급의 전부. 등록 폼이 길면 이 사람이 떠난다.
  "스팟이 망가질까 봐 공유를 꺼리는" 심리는 실재한다 → [OPEN_DECISIONS](OPEN_DECISIONS.md) 항목

### P5. 부모 / 입문 예정자 (경계 사용자, MVP 비대상)

자녀가 탈 안전한 파크를 찾는 수요. 실재하지만 **MVP에서 대응하지 않는다.**
이 수요를 쫓으면 서비스가 "체육시설 안내"로 변질된다.

## 8. 성공의 정의 (초기)

기능 개수가 아니라 아래로 측정한다.

| 지표 | 초기 목표 |
|---|---|
| 앱 실행 → 주변 스팟 마커 표시까지 | **3초 이내** |
| 첫 실행 시 화면에 스팟이 1개 이상 보이는 비율 (수도권) | 80% 이상 |
| 스팟 상세 진입률 | 실행 세션의 50% 이상 |
| 주간 신규 스팟 등록 | 10건 이상 (운영자 시딩 제외) |
| 스팟당 마지막 확인 경과일 중앙값 | 90일 이하 |

**MAU·가입자 수를 초기 목표로 삼지 않는다.** 가입은 애초에 등록/제보할 때만 요구한다.
